Resize an Image

How to resize an image

  1. Open the PixelLite editor.
  2. Upload your image.
  3. Open the resize controls and enter the required dimensions.
  4. Keep the aspect ratio locked when you want to preserve the original proportions.
  5. Apply the changes and download the result.

When should you resize an image?

Resizing is useful when an image needs to fit a specific website dimension, social media requirement, document layout or storage limit. Reducing dimensions can also reduce the resulting file size.

Preserve image proportions

Changing width and height independently can stretch or distort an image. PixelLite includes aspect ratio controls so you can maintain the original proportions while changing one dimension.

Browser based processing

PixelLite is designed to process supported image operations locally in your browser. Your image does not need to be uploaded to a PixelLite server for normal editing and export.
