Frequently Asked Questions

Common questions about PixelLite and its browser based image tools.

Is PixelLite free to use?

Yes. PixelLite's image editing and conversion tools are designed to be available without a paid editing application.

Are my images uploaded to PixelLite?

The image editing and conversion operations are performed locally in your browser. PixelLite does not need to upload the image to a server for these operations.

Which image formats can PixelLite export?

The editor supports JPG, WEBP and PNG output. The exact options shown can depend on the tool you are using.

Can I resize an image without changing its proportions?

Yes. The editor includes an aspect ratio lock. Keep it enabled when you want the width and height to change proportionally.

Can I crop an image to a specific ratio?

Yes. The editor provides free cropping as well as 1:1, 4:3, 16:9 and 2:3 aspect ratio options.

What format should I use for photographs?

JPG and WEBP are commonly suitable for photographs. You can compare the visual quality and resulting file size before downloading.

When should I use PNG?

PNG can be useful when you need lossless image storage or transparency. It is not always the smallest choice for photographs.

Does PixelLite work on mobile?

Yes. The website is designed to be responsive and the editor and converter can be used from supported mobile browsers.

Do I need to install software?

No. PixelLite is a browser based tool, so you can use the website without installing a separate image editing application.

Can I learn how to use the tools?

Yes. See the Image Tools Guide for practical information about resizing, cropping, compression and image formats.
