# PixelLite

PixelLite is a browser based image editing and conversion toolkit.

## Current tools

- Image Editor
- Image Converter
- Image Resize
- Image Crop
- Image Compression
- JPG to WEBP
- PNG to JPG
- WEBP to JPG
- JPG to PNG
- WEBP to PNG
- PNG to WEBP
- Guide and FAQ

## Privacy and processing

Supported image operations are designed to run locally in the browser. PixelLite does not require normal image editing and conversion uploads to a PixelLite processing server.

## SEO

The site includes page level titles, descriptions, canonical URLs, Open Graph metadata on the main content pages, robots.txt and sitemap.xml.

The sitemap should be submitted in Google Search Console. Avoid repeatedly requesting indexing for every page; allow the sitemap and normal crawling to discover the site.

## Final maintenance guidance

After the final SEO audit, prioritize fixing actual errors over frequent content changes. Allow search engines and advertising systems time to crawl and review the site.
