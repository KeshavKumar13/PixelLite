What is PixelLite?

PixelLite is an online image toolkit designed for common image editing and conversion tasks. You can resize, crop, adjust images, compress them and convert between supported formats from your browser.

Built for simple image workflows

PixelLite focuses on straightforward tools without requiring a desktop application. The editor provides controls for common image adjustments, while dedicated pages explain individual image tasks and formats.

Privacy focused processing

PixelLite is designed so supported image operations can run locally in your browser. Normal image editing and conversion does not require sending your image to a PixelLite server.
