Image Tools Guide

Learn how to resize, crop, compress and convert images with PixelLite.

Resize an image

Resizing changes the pixel dimensions of an image. It is useful when an image is too large for a website, email, document or social platform.

When should you resize?

  • When the image dimensions are much larger than the space where it will be displayed.
  • When you need a specific width or height in pixels.
  • When you want to reduce the amount of data an image contains before compression.

Open the PixelLite Image Editor, upload an image and use the Resize controls. Keep the aspect ratio locked when you want to avoid stretching the image.

Crop an image

Cropping removes unwanted areas around the edges of an image. It can help focus attention on the main subject or fit an image into a required shape.

Common aspect ratios

  • 1:1 for square images.
  • 4:3 for a traditional rectangular format.
  • 16:9 for wide displays and video style layouts.
  • 2:3 for a taller portrait format.

In PixelLite, select an aspect ratio and drag across the image to create the crop area.

Compress an image

Compression reduces the amount of storage space needed by an image. The result depends on the image content, format and quality setting.

JPG

JPG is commonly used for photographs and other images with many colors. Lowering quality can reduce file size, but excessive compression can make details look soft or blocky.

WEBP

WEBP is a modern image format that supports efficient compression and can be useful for websites.

PNG

PNG is useful when you need lossless image storage or transparency. PNG compression does not use the same quality slider approach as JPG and WEBP.

Tip: For photographs, try JPG or WEBP first. Compare the visual result and file size before downloading.

Convert an image

Converting changes the image file format without requiring a separate desktop application.

Use the PixelLite Image Converter to upload an image and select the output format. The conversion happens in your browser.

Does PixelLite upload my images?

PixelLite is designed to process images locally in your browser. The image editing and conversion tools do not require you to upload the image to a PixelLite server.
